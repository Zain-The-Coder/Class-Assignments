# JavaScript (ES6) Advanced Concepts – Assignment 2

## 📌 Summary

This assignment focuses on building a **deep and practical understanding of advanced JavaScript (ES6) concepts** through real experimentation rather than theory or copy-paste solutions.

Students explore how JavaScript actually behaves at runtime by writing, running, breaking, and fixing their own code. The tasks are designed so that understanding comes from **execution, observation, and reasoning**, not memorization.

### Key Areas Covered

* Advanced array methods (`map`, `filter`, `reduce`, and custom simulations)
* JavaScript behind the scenes (hoisting, execution context, call stack, closures)
* Destructuring, rest, and spread operators
* Memory behavior, references, and execution flow

### 🎯 Goal

To develop the ability to write **predictable, maintainable, and intentional JavaScript code** by understanding *why* JavaScript behaves the way it does — not just *how* to write it.

⚠️ **Strict Requirement:**
All code must be original, executed by the student, and produce unique runtime output. Submissions based on copying or AI-generated patterns without experimentation evidence will be rejected.
